# Kimer
Bold minimalist desk clock for the Samsung Galaxy Tab A6 (2016).

1. Push this repo to GitHub (branch `main`).
2. Open the **Actions** tab, wait for "Build Kimer APK" to finish (or run it by hand).
3. Download the **Kimer-APK** artifact, unzip, copy `app-debug.apk` to the tablet, install it.
   (Allow "Install unknown apps" for your file manager or browser.)
